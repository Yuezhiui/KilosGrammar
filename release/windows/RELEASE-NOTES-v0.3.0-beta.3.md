# KilosGrammar v0.3.0-beta.3

**Move. Think. Learn English grammar.**

KilosGrammar is a colorful movement-based English grammar game for Grades 1–6, built with Godot and local webcam pose recognition. Students learn by moving, answering grammar questions and playing three interactive minigames.

## Inside KilosGrammar

- **Catch the Word:** Move left, center or right to collect apples with matching grammar words.
- **Balloon Popping:** Raise your hand to shoot balloons showing the correct answers.
- **Human Plane:** Use both arms and body movement to fly through grammar-answer rings.
- **Guided tutorials:** Each game explains its question, movement controls, scores, timer, hearts and Pause control with a dimmed spotlight and voice narration. Highlight arrows are intentionally hidden for this version.
- **Student profiles and leaderboard:** Save scores from completed Play sessions locally and manage score data using CSV import and export.
- **Game choices:** Nouns, pronouns, verbs, adjectives and adverbs, with Easy/Normal/Hard difficulty, 60-second mode or three-heart Lives mode.
